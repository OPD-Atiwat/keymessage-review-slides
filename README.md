# วงคุย Key Message

สำรับสไลด์ 12 หน้าสำหรับคุยข้อความแอดของสี่เล่ม (Mind, ออฟฟิศ, Survival Guide, กับดัก) จากสแนปชอต 8 พ.ย. 2569 แคมเปญแชทเท่านั้น ไม่รวมยอดวันที่ 8 ที่ยังไม่จบวัน

ป้ายครีเอเตอร์เป็นตัวกรองในรายการแอด ไม่ใช่แกนของเรื่อง

บันทึกอยู่บนสไลด์ทุกหน้า ต้องเข้าสู่ระบบถึงจะเห็นข้อความ และเซิร์ฟเวอร์เขียนลง PostgreSQL ไฟล์อย่างเดียวหรือ GitHub Pages โชว์สไลด์ได้ แต่ขึ้นว่ายังไม่ได้บันทึก

## รันในเครื่องพร้อมบันทึก

ต้องมี Docker เครื่องนี้ไม่ได้สมัครโฮสต์ให้ และยังไม่มี URL สาธารณะที่เซฟบันทึกผ่าน

```bash
cp .env.example .env
openssl rand -hex 32   # ใส่ค่าใน SESSION_SECRET
# ตั้ง POSTGRES_PASSWORD เอง อย่าcommit .env
printf '%s' 'รหัสยาวอย่างน้อยสิบตัว' | npm run hash-password
# นำบรรทัด scrypt$... ไปใส่ EDITOR_PASSWORD_HASH
docker compose up --build
```

เปิด `http://127.0.0.1:8080` ได้เฉพาะดูสไลด์ การเข้าสู่ระบบบน HTTP จะถูกปฏิเสธเพราะคุกกี้ต้องเป็น Secure

ทางที่ใช้ได้:

1. วาง HTTPS ไว้หน้าพอร์ต 8080 แล้วตั้ง `TRUST_PROXY=1` เมื่อพร็อกซีส่ง `X-Forwarded-Proto: https`
2. บนเครื่องตัวเองชั่วคราว ใส่ `ALLOW_INSECURE_COOKIES=1` และอย่าตั้ง `NODE_ENV=production` คุกกี้จะไม่ติดธง Secure ใช้ได้แค่ HTTP ในเครื่อง

ตรวจว่าบันทึกอยู่จริง: เข้าสู่ระบบ พิมพ์บนสไลด์ กดบันทึกหรือรอสถานะ “บันทึกแล้ว” เปิดเบราว์เซอร์อีกตัว เข้าสู่ระบบ ต้องเห็นข้อความเดิม แล้ว `docker compose restart app` แล้วเปิดใหม่ ข้อความต้องยังอยู่

## สิ่งที่ยังไม่มี

ไม่มี URL ออนไลน์ในรอบนี้ เพราะการมีฐานข้อมูลถาวรต้องใช้เครื่องหรือบัญชีโฮสต์ของเจ้าของเอง และรอบนี้ไม่ได้สมัครบริการใหม่ ไม่ได้ใช้ GitLab หรือฐานข้อมูลของบริษัท

GitHub Pages ถ้าเปิดจากโฟลเดอร์ `public/` จะเป็นแค่ตัวอย่างสไลด์ สถานะบันทึกจะบอกว่ายังไม่ได้ตั้งค่า อย่าใช้ Pages เป็นที่เก็บโน้ต
